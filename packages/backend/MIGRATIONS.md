# Database migrations (Alembic)

The backend schema is managed with [Alembic](https://alembic.sqlalchemy.org/).
Migrations live in `migrations/versions/` and ship inside the package so they
travel with the deployed wheel.

## How the database URL is resolved

Alembic does **not** read a URL from `alembic.ini` (it is left blank). Instead
`migrations/env.py` resolves it the same way the app does:

1. the `MATH_PRACTICE_DATABASE_URL` environment variable, if set; otherwise
2. `math_practice_backend.settings.get_settings().database_url`
   (default: in-memory SQLite).

So one migration stack targets file/in-memory SQLite (dev, tests) and Postgres
(deploy) with no credentials committed to source control.

`env.py` uses `compare_type=True` (detect column-type changes) and
`render_as_batch=True` (so SQLite `ALTER`s run in batch copy-and-move mode). The
naming convention on `Base.metadata` (see `db.py`) keeps constraint/index names
deterministic across SQLite and Postgres.

## Startup behavior (no migration step for SQLite)

`init_db()` (called in the FastAPI lifespan) is dialect-aware:

- **SQLite** (in-memory/file dev path and the test suite): creates the schema
  in-process via `Base.metadata.create_all` — no `alembic upgrade` needed.
- **Postgres / any non-SQLite backend**: does **not** create tables. The schema
  is owned by Alembic; run `alembic upgrade head` at deploy time.

The chosen path is logged at INFO.

## Commands

Run from the backend package directory so `script_location = migrations`
resolves (or pass `--directory` to `uv`):

```bash
cd packages/backend

# Apply all pending migrations (run this on a Postgres deploy)
MATH_PRACTICE_DATABASE_URL=postgresql+psycopg://user:pass@host/db \
  uv run --package math-practice-backend alembic -c alembic.ini upgrade head

# Inspect state
uv run --package math-practice-backend alembic -c alembic.ini current
uv run --package math-practice-backend alembic -c alembic.ini history

# Autogenerate a new revision after changing models.py
# (point at a fresh DB that already has prior migrations applied, or a throwaway
#  empty SQLite db to diff the full schema)
MATH_PRACTICE_DATABASE_URL=sqlite+pysqlite:////tmp/mp_gen.db \
  uv run --package math-practice-backend alembic -c alembic.ini \
  revision --autogenerate -m "describe the change"

# Roll back one revision
uv run --package math-practice-backend alembic -c alembic.ini downgrade -1
```

Always review an autogenerated migration before committing it — Alembic detects
renames as drop+add, and may miss server-side defaults or type nuances.

## Postgres driver

The Postgres driver is an optional dependency:

```bash
uv sync --extra postgres --package math-practice-backend
```

Use a `postgresql+psycopg://...` URL (psycopg 3).
